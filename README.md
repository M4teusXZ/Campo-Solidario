# 🌱 Campo Solidário | Conectando o Campo à Cidade

Uma plataforma web desenvolvida para conectar agricultores e instituições, reduzindo o desperdício de alimentos e fortalecendo a solidariedade entre o campo e a cidade.

---

# 🎯 Objetivo do Projeto

O Campo Solidário foi desenvolvido com o objetivo de reduzir o desperdício de alimentos no meio rural, conectando agricultores a instituições que necessitam de doações.

Muitos alimentos acabam sendo descartados por fazendas, mercados e empresas devido a pequenos detalhes estéticos, como:

* tamanho irregular
* pequenas manchas
* aparência fora do padrão comercial

Mesmo estando em perfeitas condições para consumo.

Pensando nisso, a plataforma permite que agricultores registrem esses alimentos excedentes para que instituições possam visualizá-los e entrar em contato para realizar a coleta.

Dessa forma, alimentos que seriam desperdiçados passam a cumprir um papel social importante, ajudando famílias e instituições enquanto fortalecem a conexão entre o campo e a cidade.

Além disso, o projeto também busca promover:

* sustentabilidade
* inclusão social
* acessibilidade digital
* conscientização sobre desperdício de alimentos

# 🛠️ Recursos Técnicos

## ♿ Hub de Acessibilidade (Custom JS)

O projeto possui um painel de acessibilidade exclusivo que permite:

- **Controle de Fonte:** ajuste dinâmico do tamanho do texto.
- **Dark Mode:** modo noturno com troca completa de identidade visual.
- **Interface Adaptável:** experiência responsiva para diferentes dispositivos.

---

## 💬 Sistema de Doações

A plataforma conta com:

- cadastro dinâmico de novas doações
- exibição automática para instituições
- filtro por categorias
- data e horário de registro
- chat individual para cada doação
